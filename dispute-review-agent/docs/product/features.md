# 司乘纠纷审查 Agent — 产品功能

## 核心定位
AI 驱动的滴滴司乘纠纷智能审查系统，通过大语言模型自动分析双方陈述、交叉验证证据、匹配平台规则，输出结构化裁决建议与置信度评分。

## 功能列表

### 1. 纠纷仪表盘
- **案件统计概览**：总案件数、待审查、审查中、已裁决四项核心指标卡片
- **案件列表表格**：展示所有纠纷案件，含案件编号、标题、类型、优先级、状态、创建时间
- **快速操作**：每行案件可一键跳转详情页，顶部按钮快速提交新案件

### 2. 案件提交
- **案件信息**：标题、纠纷类型（绕路/爽约收费/财物损坏/安全事故）、优先级（低/中/高/紧急）
- **司机信息**：姓名、工号、历史评分、事件陈述
- **乘客信息**：姓名、账号、历史评分、事件陈述
- **行程详情**：起终点、上下车时间、车费、距离、车型、车牌
- **证据管理**：证据描述 + 可增删的证据项动态列表
- **表单校验**：前端必填校验 + 后端 Zod Schema 双重验证

### 3. AI Agent 审查
- **一键启动审查**：对待审案件触发 AI Agent 自动分析
- **审查加载状态**：展示 AI 正在分析的关键步骤提示
- **结构化审查报告**：
  - **裁决建议**：支持司机 / 支持乘客 / 双方共担 / 无法判定
  - **置信度评分**：0-100 分 + 颜色渐变进度条
  - **案件摘要**：AI 生成的一句话摘要
  - **关键争议点**：识别的核心争议列表
  - **司机方分析**：司机立场与可信度评估
  - **乘客方分析**：乘客立场与可信度评估
  - **证据分析**：证据对各方主张的支持度评估
  - **适用规则**：匹配的网约车平台政策与规则
  - **裁决理由**：详细的建议理由说明
  - **置信度说明**：评分依据分析
  - **建议措施**：具体的后续处理建议列表

### 4. 案件详情
- **案件头部**：编号、状态徽章、优先级徽章、类型徽章、创建时间
- **双方对比**：司机与乘客信息卡片并排展示
- **行程信息**：结构化展示完整行程数据
- **证据信息**：证据描述与证据项清单
- **AI 审查报告**：完整的结构化分析报告

### 5. 证据知识库与智能问答
- **证据上传**：支持 PDF、文本（txt/md/csv/json）、截图与照片，可关联到具体案件，或作为全局资料（如平台政策、司机手册）
- **自动解析**：PDF 按页提取文字；截图/照片通过 OCR 识别中英文文字（可选视觉模型生成图片描述）
- **公司内部记录**：从内部 API 拉取纠纷工单、行程（GPS 轨迹、聊天记录、App 事件）、乘客与司机档案（当前为模拟接口）
- **向量检索**：文本切块后生成向量存入 pgvector，按语义相似度检索，可限定案件与资料类型
- **智能问答**：输入问题 → 检索相关证据 → 本地大模型基于证据作答，并以 [1][2] 标注引用来源
- **去重与重试**：同一案件重复上传的文件自动去重；处理失败的文件可一键重新处理

## 技术架构
- **前端**：React 19 + Vite + TanStack Query + shadcn/ui + Tailwind CSS 4
- **后端**：Express + TypeScript + Zod 校验
- **AI 审查**：Tencent Hunyuan (TokenHub) 大语言模型，零配置沙箱代理
- **知识库**（全部开源免费，本地运行）：PostgreSQL + pgvector（数据库与向量检索）、Ollama（模型服务）、bge-m3（向量模型）、Qwen2.5（问答模型）、unpdf（PDF 解析）、tesseract.js（OCR）
- **设计风格**：专业深蓝侧边栏 + 浅色主内容区，信任感与权威感
